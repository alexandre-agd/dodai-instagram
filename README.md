# dodai-instagram

Images des carrousels Instagram de Dodai Studio (@dodaistudio), servies à Buffer
pour la publication. Un dossier par semaine ISO (`2026-s44/`), un fichier par vue
(`<post>-01.jpg`, `<post>-02.jpg`…).

Rempli chaque vendredi par la routine « Instagram de la semaine ». Ne rien y
déposer d'autre : tout ce qui est ici est public.
